# Security

This is a static website with no server, accounts or stored personal data. The most likely issues are cross-site scripting through crafted data or translations, or a compromised dependency (fonts are loaded from Google Fonts).

If you find a vulnerability, please **don't open a public issue**. Report it privately through GitHub (*Security › Report a vulnerability* on this repository) or by e-mail to **3dpThingies@proton.me**. We'll reply as soon as we can.
